# Keyboard Shortcuts

On a Mac, use **⌘** (Command) wherever this page says **Ctrl**, and **⌥** (Option) for **Alt**.

## Anywhere in the app

| Keys | Action |
|---|---|
| Ctrl+Shift+D | Go to the Dashboard |
| Ctrl+Shift+E | Go to the Editor |
| Ctrl+Shift+G | Go to the Graph |
| Ctrl+Shift+T | Go to Tasks |
| Ctrl+Shift+V | Go to Version Control |
| Ctrl+Alt+C | Go to the Compiler |
| Ctrl+Shift+H | Go to Help |
| Ctrl+Shift+S | Go to Settings |
| Ctrl+, | Open Settings (from the File menu) |
| Ctrl+N | New project (from the File menu; on the Tasks page it creates a task instead) |
| Ctrl+O | Open a project |
| Ctrl+Plus and Ctrl+Minus | Make everything larger or smaller |
| Ctrl+0 | Reset the size |
| Ctrl+Q | Quit (⌘Q on a Mac) |

The **Ctrl+Shift** shortcuts don't work while you're typing in a box or in the Editor. Ctrl+Alt+C works everywhere.

## Editor

| Keys | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+P | Show or hide the preview |
| Ctrl+B | Bold |
| Ctrl+I | Italic |
| Ctrl+K | Insert a link |
| Ctrl+Shift+L | Link this page to another page |
| Ctrl+Click | Open the page a link points to |
| Ctrl+F | Find in this page |
| Ctrl+H | Find and replace |
| Alt+Up or Alt+Down | Move the line up or down |

## Graph

These work while the Graph is open and you're not typing.

| Keys | Action |
|---|---|
| Delete or Backspace | Delete the selected cards (you'll be asked to confirm) |
| Esc | Clear the selection or close a menu |
| A | Turn Rigid mode on or off |
| U | Show or hide uploaded files |

Right-click a card, a link or the background for more actions.

## Tasks

| Keys | Action |
|---|---|
| Ctrl+N | Create a task |
| Esc | Close a dialog |

## Version Control

| Keys | Action |
|---|---|
| Ctrl+Enter | Save a version |
| Ctrl+R | Refresh the list of changes |

## Help

| Keys | Action |
|---|---|
| Ctrl+F | Find in the open guide; F3 and Shift+F3 move between matches |
