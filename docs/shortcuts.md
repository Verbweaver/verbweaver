# Keyboard Shortcuts

This document lists hotkeys that are currently implemented in Verbweaver. On macOS, replace Ctrl with Cmd where applicable.

## Global (anywhere in the app)
- Ctrl + Shift + D: Dashboard
- Ctrl + Shift + E: Editor
- Ctrl + Shift + G: Graph
- Ctrl + Shift + T: Tasks
- Ctrl + Shift + V: Version Control
- Ctrl + Shift + H: Help
- Ctrl + Shift + S: Settings
- Ctrl + Alt + C: Compiler

Notes:
- Global shortcuts are ignored while typing in inputs, textareas, or content‑editable fields, except Ctrl + Alt + C (Compiler), which works anywhere.

## Editor
- Ctrl + S: Save current file
- Ctrl + P: Toggle preview mode
- Ctrl + B: Toggle bold (Markdown)
- Ctrl + I: Toggle italic (Markdown)
- Ctrl + K: Insert link (Markdown)
- Ctrl + Shift + L: Create Link (open Create Link modal)

Monaco default bindings (subset):
- Ctrl + F: Find in file
- Ctrl + H: Replace in file
- Ctrl + D: Add selection to next find match
- Alt + Up/Down: Move line up/down
- Alt + Shift + Up/Down: Copy line up/down
- Ctrl + /: Toggle line comment

## Graph
- Delete/Backspace: Delete selected node(s) or edge
- Esc: Clear selection / close context menu
- A: Toggle “Rigid Mode” (when graph has focus)
- U: Toggle “Hide Uploads” (when graph has focus)
- Right‑Click: Open node/edge context menu

## Tasks
- Ctrl + N: New Task (Board/To‑Do)
- Esc: Close dialogs

## Version Control
- Ctrl + Enter: Commit staged changes
- Ctrl + R: Refresh status/history

If you spot missing or incorrect shortcuts, please open an issue or PR to update this document.
